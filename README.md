# 🎥 Distraction-Free Videos

A simple HTML project that provides a distraction-free way to watch YouTube videos by organizing them into categories.

## 📖 About

This project was created while learning HTML fundamentals. It demonstrates how to build a multi-page website using only HTML, without CSS or JavaScript.

## ✨ Features

- Home page with video categories
- Coding videos
- Music videos
- Gaming videos
- Embedded YouTube videos using `<iframe>`
- Navigation between pages using HTML links

## 🛠️ Technologies Used

- HTML5
